# HBB Gene and E6V Mutation – Bioinformatics Analysis

🧬 This repository contains a bioinformatics analysis of the Human HBB gene and the E6V mutation responsible for Sickle Cell Disease.

## 📌 Project Overview

The HBB (Hemoglobin Subunit Beta) gene plays a critical role in oxygen transport within red blood cells.  
This project focuses on analyzing the E6V missense mutation that causes Sickle Cell Anemia using fundamental bioinformatics tools.

---

## 🛠️ Tools Used

- NCBI Gene  
- BLAST  
- UniProt  
- Clustal Omega  
- Variant Effect Predictor (VEP)
